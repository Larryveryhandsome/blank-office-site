# blank-office-site｜留白事務所官網

留白事務所（The Blank Office）的官方網站原始碼：專為忙碌老闆打造的**全託管網頁設計服務**。

- 網站：https://larryveryhandsome.github.io/blank-office-site/
- 諮詢：[LINE 官方帳號](https://lin.ee/KaZ8bgl)

## 內容

單一頁面 `index.html`，不需要建置工具：

| 區塊 | 說明 |
|---|---|
| 首頁主視覺 | 「為您的時間留白」品牌主張 |
| 老闆的煩惱 | 網站不更新、出問題找不到人、維護費像無底洞 |
| 雲端工務部 | 全託管、快速修改、月費制 |
| 作品集 | 各產業示範網頁（牙醫、旅宿、民宿、建設公司、建案、工程行、動物醫院、農場） |
| 方案價格 | 一站式建置、全託管月費方案 |
| 常見問題 | 月費制、解約、修改、建置時程 |

## 自己改來用

這份版面可以拿去做你自己的服務介紹頁（Apache-2.0）：

1. 下載 `index.html`，用記事本或 VS Code 打開。
2. 把品牌名稱、文案、價格、LINE 連結換成你自己的。
3. 顏色在檔案最上面的 `:root`（`--color-navy` 等）。
4. 上傳到 GitHub，開 **Settings → Pages → Deploy from a branch → main / (root)**，幾分鐘後就有網址。
